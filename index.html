Local CLI for AI-assisted merges

Your coding agent says it’s done. Check the final tree.

Git tells you what changed. SpecPort verifies whether the scope or pinned review you approved still covers the exact tree you are about to merge. It flags uncovered paths and weak identity before the change moves on.

$ npx --yes @specport/specport@latest coverage

Why and when to adopt

Add a receipt where approval happens outside the final PR gate.

Git lists changed files. CI runs checks. SpecPort adds value when a local review, agent handoff, or explicit scope was approved before the branch stopped moving.

Worth adding when

Your approval source can drift from the merge candidate.

  • A local or agent review is the approval object.
  • Work changes hands before it reaches a hosted PR.
  • You need a machine-readable, fail-closed receipt.

Probably redundant when

Your forge already requires fresh review on every final commit.

  • The final tree cannot merge after approval goes stale.
  • CODEOWNERS and branch protection cover the real risk.
  • You do not need an off-platform approval receipt.
